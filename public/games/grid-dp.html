Grid Path DP Trainer

Every cell asks one question: how did I get here? Only from above or from the left. You fill the table, and the code shows which line you just ran.

The code, live

The recipe you can reuse for every grid DP

1. Name the cell

dp[i][j] = the answer if the grid ended at (i, j): ways to reach it, cheapest cost to reach it, most coins on arrival.

2. Look up and left

Moves are right or down, so you can only arrive from (i−1, j) or (i, j−1). Combine those two: add, min, or max.

3. Rocks and off-grid get the identity

Give them the value that can't affect the combine. Then the same line of code works on edges and next to rocks.

4. Seed only the start

Set dp[0][0] directly. Don't hard-code the whole first row or column. That shortcut is where most rock bugs come from.

5. Fill in dependency order

Any order works as long as top and left are done before the cell. Row by row is the usual choice. That's also why a single row is enough memory.
